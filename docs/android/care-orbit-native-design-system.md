# Care Orbit Native Design System Baseline

Preserve Matrigluco identity, calm care language and orbit metaphor while using Android-native behavior. XML custom views/styles own tokens; Material components are implementation primitives, not the visual identity. Provide semantic color roles (care green, Care Pink for supportive/high-attention accents—not diagnosis, surfaces, ink, outline, success/warning/error), typography and spacing tokens, 48dp touch targets, visible focus, TalkBack labels, font scaling, reduced motion and contrast-compliant light/dark themes.

Phone layouts prioritize one-handed bottom navigation and system back/predictive back. Tablets use resource-qualified adaptive panes, never stretched phone cards. Loading, empty, offline, unavailable and error states are first-class. No fabricated readings. Phase 2 must derive exact tokens from the existing web Care Orbit reference and verify both themes before feature screens.
